# Анализ зарплат специалистов в области Data Science

Лабораторная работа по дисциплине «Методология анализа данных».

## Цель

Выявить три фактора, сильнее всего влияющих на годовую зарплату специалиста по данным, и оценить их влияние.

## Данные

[Data Science Job Salaries](https://www.kaggle.com/datasets/ruchi798/data-science-job-salaries).

## Содержание блокнота

| Раздел |
|---|
| 1. Введение и постановка цели | цель, задачи, гипотезы H1-H6 |
| 2. Предварительный обзор данных | размер, типы, пропуски, дубликаты, базовые статистики |
| 3. Предобработка данных | удаление дубликатов и лишних столбцов, анализ выбросов, новые признаки |
| 4. Исследовательский анализ | распределения, корреляции, проверка гипотез непараметрическими тестами |
| 5. Визуализация | боксплоты, violin plot, тепловая карта, точечные графики |
| 6. Моделирование | сравнение шести моделей, важность признаков, линейная регрессия, анализ ошибок |
| 7. Выводы | итоги проверки гипотез и топ-3 фактора |

## Результаты

Сильнее всего на зарплату влияют регион компании, уровень опыта и категория должности.

## Запуск

Нужен Python 3.13. Я запускал блокнот в Anaconda с такими версиями библиотек:

| Библиотека | Версия |
|---|---|
| pandas | 2.3.3 |
| numpy | 2.3.5 |
| matplotlib | 3.11.1 |
| seaborn | 0.13.2 |
| scipy | 1.16.3 |
| scikit-learn | 1.9.0 |
| statsmodels | 0.14.5 |
| catboost | 1.2.10 |

Установка:

```bash
pip install pandas numpy matplotlib seaborn scipy scikit-learn statsmodels catboost
```

Затем открыть `Lab.ipynb` и выполнить все ячейки по порядку. Файл `ds_salaries.csv` должен лежать рядом с блокнотом.
